## 📌 Executive Summary

This repository contains the complete research framework, PyTorch neural architectures, psychological VAD grounding lexicons, vector figure generation pipelines, and publication-ready IEEE Transactions LaTeX source code for:

> **"Adversarial Affective Representation Disentanglement with Adaptive Prototype Margins for Long-Tailed Text Emotion Recognition"**

Fine-grained text emotion classification discriminates among six affective categories under severe class imbalance:
1. `Sadness` (4,661 samples, 29.27% of clean training split)
2. `Joy` (5,340 samples, 33.54% of clean training split)
3. `Love` (1,283 samples, 8.06% of clean training split)
4. `Anger` (2,152 samples, 13.52% of clean training split)
5. `Fear` (1,923 samples, 12.08% of clean training split)
6. `Surprise` (564 samples, 3.54% of clean training split — *extreme minority class, 9.47:1 imbalance ratio*)

## 🔬 Multi-Tier Dataset Audit & Strict Leakage Control

To guarantee rigorous scientific reproducibility, all training and evaluation protocols are executed on strictly audited splits with zero contamination:
- **Clean Training Set**: **15,923 samples** (77 defective instances excised: 16 cross-split duplicates, 4 within-train duplicates, and 57 conflicting label pairs).
- **Clean Validation Set**: **1,993 samples** (7 test-overlapping instances excised).
- **Official Test Set**: **2,000 samples** (strictly preserved and uncontaminated).

## 🔬 Core Innovations & Theoretical Grounding

Our framework unifies three distinct research pillars designed to overcome class imbalance and spurious context-affect correlation:

1. **Structural Causal Formulation**:
   - Modeled via a Directed Acyclic Graph (DAG) $X \leftarrow (A, C)$, where text $X$ is jointly generated by invariant affective intent $A$ and syntactic/topical context $C$.
   - Latent representation $h$ is partitioned into orthogonal subspaces:
     - $z_a \in \mathbb{R}^{256}$: Pure Affective Subspace.
     - $z_c \in \mathbb{R}^{256}$: Context / Syntax Subspace.

2. **Adversarial Emotion Erasure (GRL) & Subspace Orthogonality**:
   - A Gradient Reversal Layer (GRL) is applied to $z_c$, forcing the discriminator to fail at predicting emotion labels and purging sentiment leakage from the contextual channel.
   - A cosine orthogonality penalty $\mathcal{L}_{\text{ortho}}$ ensures $z_a \perp z_c$.

3. **Adaptive Prototype Margins with Generalization Bounds**:
   - Class prototypes $P_k$ normalized on the unit hypersphere ($\|P_k\|_2 = 1$).
   - Dynamic class-dependent margin:
     $$\Delta_y = \frac{\alpha}{n_y^{1/4}}$$
   - Expanding the Voronoi decision boundary for sample-scarce classes (*Surprise* and *Love*), provably bounding minority classification error under Proposition 1.

## 💻 Quickstart Reproduction

```bash
# 1. Clone repository
git clone https://github.com/nishantkumar-AIML/sentiment.git
cd sentiment

# 2. Set up virtual environment
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Setup NRC-VAD lexicon, audit splits, and compute anchors (Step 1)
python3 step1_setup_vad_data.py

# 4. Verify dataset split breakdown and hyperparameter specifications (Reproduces Tables 1 & 2)
python3 verify_dataset_stats.py

# 5. Run Classical Benchmark Suite (Reproduces Table 4 classical baselines)
python3 benchmark_classical_updated.py

# 6. Run SOTA Transformer & Proposed Disentangled Framework (Step 3)
python3 run_single_experiment.py ModernBERT_Baseline
python3 run_single_experiment.py Proposed_Framework_Full

# Optional: Run individual ablation experiments (Reproduces Table 6)
# python3 run_single_experiment.py Ablation_No_Ortho
# python3 run_single_experiment.py Ablation_No_Adv
# python3 run_single_experiment.py Auxiliary_Continuous_VAD

# 7. Generate Publication-Ready Vector PDF Figures (Step 4)
python3 generate_new_paper_figures.py

# 8. Compile IEEE Transactions LaTeX Manuscript
cd paper
/Library/TeX/texbin/pdflatex -interaction=nonstopmode research_paper.tex
/Library/TeX/texbin/pdflatex -interaction=nonstopmode research_paper.tex
cd ..
```
